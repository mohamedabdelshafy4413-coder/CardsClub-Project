# Cards Club — International Export Command Center

A fast Streamlit dashboard and structured export study for Cards Club, focused on GCC + Africa.

## What is included
- 50-country market prioritization for HS 950440 (Playing Cards)
- Brand / portfolio architecture and positioning
- Export risk register and mitigation controls
- Customs / trade-agreement control layer
- Golden 1000 account model
- 90-day GTM and export execution roadmap
- 7 outbound email campaign angles
- Sales scenarios and KPI tree
- Sanitized runtime data only

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
