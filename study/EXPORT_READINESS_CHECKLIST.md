# Cards Club — Export Readiness Checklist

This checklist is the operating gate before outbound scale, quotations and shipment.

## A. Product master data
- [ ] Final SKU names and codes
- [ ] Correct country of origin on every listing and label
- [ ] Barcode / GTIN where required
- [ ] Unit dimensions and weight
- [ ] Inner / master carton configuration
- [ ] Master-carton dimensions, gross/net weight and CBM
- [ ] Paper/card stock specification
- [ ] Coating / finish specification
- [ ] Print method and color tolerance
- [ ] Standard lead time and peak-season lead time
- [ ] Factory capacity claim verified internally

## B. Customs / origin
- [ ] Destination HS classification confirmed
- [ ] HS 950440 validated for the actual product configuration
- [ ] Applicable trade agreement checked
- [ ] Rules of Origin checked
- [ ] BOM and Egyptian value-added calculation prepared
- [ ] Certificate of Origin route confirmed
- [ ] Required exporter/importer registrations confirmed
- [ ] Destination labeling / marking checked
- [ ] Product conformity / inspection route checked

## C. Commercial structure
- [ ] EXW price
- [ ] FOB price
- [ ] CIF quotation workflow
- [ ] Trial MOQ
- [ ] Standard MOQ
- [ ] Strategic distributor MOQ
- [ ] Volume discount rules
- [ ] Quote validity policy
- [ ] Sample policy
- [ ] Design/setup fee policy for BrandLab
- [ ] Revision / change-order rules
- [ ] Payment terms matrix by risk level

## D. Quality and packaging
- [ ] Golden Sample approved
- [ ] Paper thickness / GSM locked
- [ ] Coating / shuffle feel locked
- [ ] Cut and edge tolerances locked
- [ ] Color tolerance documented
- [ ] Packaging artwork approved
- [ ] Moisture-control packaging assessed by route
- [ ] Dry-container / desiccant requirement assessed
- [ ] Batch QC sign-off before shipment

## E. Distributor control
- [ ] Company registration checked
- [ ] Import capability checked
- [ ] Channel coverage verified
- [ ] Trade references / payment history checked
- [ ] Sales forecast requested
- [ ] Marketing commitment agreed
- [ ] Territory defined
- [ ] Channel rights defined
- [ ] Exclusivity tied to performance
- [ ] Minimum annual purchase defined
- [ ] Termination / loss-of-exclusivity clause defined

## F. IP / design
- [ ] Client confirms rights to logos / trademarks / images
- [ ] IP warranty included in order terms
- [ ] Local trademark screen for country editions
- [ ] Cultural / religious / national-symbol review completed
- [ ] Final artwork approval recorded
- [ ] Revision limit recorded

## G. Shipment gate
- [ ] PO and contract confirmed
- [ ] Payment security confirmed
- [ ] Incoterm confirmed
- [ ] Commercial invoice checked
- [ ] Packing list checked
- [ ] COO route checked
- [ ] Conformity / shipment certificate checked where relevant
- [ ] Freight booking confirmed
- [ ] Cargo insurance confirmed where required
- [ ] QC released
- [ ] Export documents archived

## H. Outbound readiness
- [ ] Sending domain isolated from critical corporate mail where appropriate
- [ ] SPF / DKIM / DMARC configured
- [ ] Contacts verified
- [ ] Country × segment × offer micro-campaign built
- [ ] 1–2 decision makers per account targeted
- [ ] Positive-reply definitions agreed
- [ ] CRM stages defined
- [ ] Objection tags defined
- [ ] Follow-up cadence approved
- [ ] Weekly KPI review scheduled

## Hard stop rules
1. **No mass outreach** before product and commercial data are clean.
2. **No duty-free promise** before product-specific Rules of Origin and destination treatment are validated.
3. **No final landed-price promise** without current freight and destination charges.
4. **No shipment** before payment, conformity, documentation and QC gates are cleared.
5. **No permanent exclusivity** from one pilot order.
6. **No public repository upload** of credentials, banking details or confidential internal workbooks.
