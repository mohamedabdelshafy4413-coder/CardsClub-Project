# Runtime Data

This folder contains the sanitized data used by the Streamlit dashboard.

- `countries.csv` — 50-country priority model and scoring
- `products.csv` — product / offer architecture
- `risks.csv` — 25 export risks and mitigations
- `roadmap.csv` — 90-day GTM execution plan
- `golden1000.csv` — target-account segmentation model
- `trade.csv` — customs / trade framework controls
- `sources.csv` — research source register

## Security
The raw internal workbook is **not** stored here because it contains sensitive operational, credential and banking-related information. Buyer-facing data should only come from validated, sanitized master data.
